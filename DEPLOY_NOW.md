## 🆘 If Anything Goes Wrong

### Build Failed?
```bash
# Test locally first
npm run build
npm run lint
npx tsc --noEmit
```

### API Key Issues?
- Check Vercel dashboard → Project → Environment Variables
- Make sure `NEXT_PUBLIC_GEMINI_API_KEY` is set

### Features Not Working?
- Open browser console (F12) → Check for errors
- API key might not be loading
- Try restarting the deployment
